# 🎓 Ecossistema de Agentes & Skills do GitSimulador

Este diretório contém a estrutura de agentes autônomos, diretrizes de workspace e **Skills especializadas** do projeto.

---

## 🤖 Agentes Especializados

### 1. `git-tutor-pedagogico`
- **Papel:** Tutor Pedagógico Especialista em Ensino de Git para Iniciantes.
- **Foco:** Andaimes cognitivos (*scaffolding*), modelos mentais visuais, acolhimento de erros e desmistificação do terminal.
- **Skills Associadas:**
  - `git-mental-models`: Analogias das 3 áreas de trabalho, post-its de branches e agulha do HEAD.
  - `git-error-rescuer`: Resgate acolhedor de erros, conflitos de merge e push rejeitado.
  - `git-missions-scaffolding`: Roteiros práticos de desafios graduais em 4 níveis.

### 2. `designer-uiux-especialista`
- **Papel:** Senior Product Designer & UI/UX Design System Specialist.
- **Foco:** Criação de interfaces modernas, sistemas de tokens, microinterações, paletas com contraste harmônico (WCAG) e acabamento estético de nível internacional (Tailwind CSS, React 19, Next.js).
- **Skills Associadas:**
  - `ui-design-tokens-and-theming`: Camadas de profundidade em Dark Mode, bordas sutis e paletas de cores semânticas.
  - `ui-ux-microinteractions-and-states`: 7 estados obrigatórios de UI (hover, active, focus-visible, loading, empty), feedback tátil e animações suaves.
  - `ui-accessibility-and-hierarchy`: Diretrizes de acessibilidade WCAG 2.1 AA/AAA, contraste 4.5:1, ergonomia de toque e redução de ruído visual.
